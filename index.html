3Use in Power BI

View, Themes, Browse for themes. Then Format page, Canvas background, Image (transparency 0%, fit "Fit"). Match the size under Canvas settings, Type.

Good to know

  • The background PNGs hold shapes only and no text: bands, nav button shapes, card tiles, KPI icons and the KPI color stripe. With tiles on, the theme makes visuals transparent so they sit on the tiles.
  • The heading text, logo, nav buttons, KPI cards, charts and tables in the preview are placeholders. Add your own visuals over the open areas.
  • Chart types, bar width, table options and alignment are preview-only. Set them in Power BI under each visual's Format pane. Chart title alignment is the exception and goes into the theme.
  • The theme JSON carries your brand data colors, status colors (good, neutral, bad, null), heading and body text colors, and fonts. Use fonts Power BI ships with, because other fonts only render where installed.
  • Tile shadows are drawn into the PNG. Hover effects cannot be stored in an image, so they only show in this preview. In Power BI use each visual's Effects settings or button hover states.
  • Landing page: use the landing PNG as the canvas background of page 1. Add text boxes for the heading and description, and a button linking to page 2, over the shapes.
  • "Preview with text" saves the page exactly as shown, with text and values, for sharing or reference. Power BI still needs the text-free background.
